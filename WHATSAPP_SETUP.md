# Alertas de clientes por WhatsApp

El botón **Enviar datos a WhatsApp** abre un chat con el número `+57 314 779 4691` y prepara un mensaje con los datos del cliente y del préstamo (monto, interés, total, frecuencia, cuotas y fecha límite). Funciona con un cliente existente seleccionado o con los datos de un cliente nuevo.

WhatsApp no permite enviar el mensaje automáticamente con este método: revísalo y pulsa **Enviar** en WhatsApp. No se necesita una cuenta de Meta, token ni configuración adicional. Si el navegador bloquea la ventana emergente, usa el enlace que aparece debajo del formulario. El botón solo prepara y abre el mensaje; no registra al cliente ni el préstamo.

El mensaje incluye datos personales del cliente. Confirma que tienes autorización para compartirlos por WhatsApp.
