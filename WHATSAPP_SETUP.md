# Alertas de clientes por WhatsApp

El botón **Enviar datos a WhatsApp** abre un chat con el número `3205486261` y prepara un mensaje con los datos del cliente y del préstamo (monto, interés, total, frecuencia, cuotas y fecha límite). El calendario parte de la fecha de inicio editable, que por defecto usa la fecha de registro del cliente seleccionado; para un cliente nuevo, también se guarda como su fecha de registro. Las cuotas se calculan según esa fecha, la frecuencia y el número de cuotas. También incluye un enlace de Google Calendar para crear un evento el día del vencimiento; al abrirlo, configura una notificación y guarda el evento. Funciona con un cliente existente seleccionado o con los datos de un cliente nuevo.

WhatsApp no permite enviar el mensaje automáticamente con este método: revísalo y pulsa **Enviar** en WhatsApp. No se necesita una cuenta de Meta, token ni configuración adicional. Si el navegador bloquea la ventana emergente, usa el enlace que aparece debajo del formulario. El botón solo prepara y abre el mensaje; no registra al cliente ni el préstamo.

El mensaje incluye datos personales del cliente. Confirma que tienes autorización para compartirlos por WhatsApp.
